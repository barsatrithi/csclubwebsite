Member Starter Page

First Member Starter

This is the first example member page for the club site. Future members can branch off, duplicate this structure, and turn it into a personal page, project gallery, resume hub, or a launch point to an outside portfolio.

Back to Members Example External Link

About This Pattern

One page per member keeps ownership simple.

Each student can own a single HTML file inside the members/ folder and update it however they want, as long as the page keeps the shared site styling and links back to the club hub.

If a student already has a personal website, the member card can point there instead. That way the club hub still works like a directory without forcing everyone into the same page format.

Suggested Sections

  • Short intro and academic year
  • Technical interests or coursework
  • Projects, GitHub, or portfolio links
  • Fun facts, clubs, or campus involvement
  • Preferred contact links

What Future Contributors Would Do

Recommended workflow for a new member page

  • Create a new branch from the latest members-page branch or from main after this feature lands.
  • Duplicate this file with a clear name like members/jane-doe.html.
  • Update the card entry on members.html or in the members data source with the new page URL.
  • Open a pull request so the club can review the page before it goes live.

Ideas

Ways a student can make the page their own

  • Add project screenshots, hackathon recaps, or research interests.
  • Turn the page into a polished portfolio with resume and social links.
  • Use it as a lightweight homepage that grows over several semesters.
